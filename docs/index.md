## About these documents

- The **numbers in the documentation are measured on this machine** (Python 3.10.12 + PyQt5 5.15.6, Ubuntu 22.04), not estimates;
  the commands that produced them are given in the relevant sections, so you can recompute them yourself.
- If you change behaviour in code, **please update all three languages in the same pass** (see [Contributing](contributing.md)).
- Anything not yet verified is marked explicitly instead of being written as "should work".
